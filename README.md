# KidsCanvas

KidsCanvas is a small drawing and coloring app for the Computer Graphics Sessional project. Its drawing pixels are generated by classical CG algorithms and rendered with Python OpenGL and GLUT.

## Run

Install the Python packages in `requirements.txt`. On Ubuntu, also install FreeGLUT:

```bash
sudo apt install freeglut3-dev
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

## Controls

- The left sidebar contains a saturation/value gradient picker, draggable hue and opacity sliders, RGB channel controls, a shaded preset-color grid, and the drawing tools. Click or drag the picker controls to choose a color.
- Choose a drawing tool from the left sidebar and click on the canvas. Line, circle, and rectangle use two points; triangle uses three.
- Choose **CURVE**, click connected points, then press **Enter** to finish. **Backspace** removes the last unfinished point. Curves are polylines made from Bresenham line segments; the app does not use Bezier curves.
- Choose a color from the picker or preset grid before drawing or filling. Lower the opacity slider for translucent strokes.
- **FILL** uses Flood Fill. **BOUND** uses Boundary Fill and expects the dark outline color.
- Choose **CLIP**, click two opposite corners to set a rectangular clipping window, then draw lines with **LINE**. New lines are clipped to that window. Press **X** to remove the window.
- Choose **PAN** and drag, or drag with the middle mouse button. Use the wheel to zoom around the pointer.
- **Ctrl-click** near an object to delete that object. **ERASE** and Ctrl-click both remove individual objects.
- Press **C** to clear the full canvas, **Ctrl+Z** to undo, **Ctrl+Y** to redo, and **Esc** to close.

## Computer Graphics techniques

| Technique | KidsCanvas use |
| --- | --- |
| Line and shape drawing | Bresenham line and circle pixels; rectangles and triangles use connected Bresenham edges |
| 2D transformations | Zoom and pan; clicks are converted between screen and canvas coordinates |
| Color fill | Iterative Flood Fill and Boundary Fill on a raster view of the drawing |
| Line clipping | Cohen–Sutherland clips new line segments to the selected rectangle |

The algorithm layer is kept separate from the OpenGL interface so each function can be explained and demonstrated independently during the viva.

## Source layout

- `algorithms/` contains the standalone algorithms and coordinate conversion helpers.
- `tools/drawing_tools.py` converts points into pixel lists for drawing tools.
- `main.py` handles the OpenGL window, toolbar, input, object storage, and rendering.
